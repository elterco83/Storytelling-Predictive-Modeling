## Storytelling y Modelos Predictivos — Análisis Logístico

Trabajo final de la carrera de Data Science (Coderhouse), aplicado sobre un dataset real de +300.000 registros de entregas.

**Contenido:**
- Limpieza y consolidación de entregas únicas
- Segmentación georreferenciada de zonas según nivel de actividad (Google Maps)
- Modelo de regresión lineal para anticipar el volumen mensual de entregas
- Clustering de clientes recurrentes
- Modelo de Gradient Boosting aplicado a la predicción de demanda

**Objetivo:** generar información útil para planificación operativa, asignación de recursos y toma de decisiones comerciales.
